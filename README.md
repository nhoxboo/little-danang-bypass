# Little DaNang - Play Direct Without Install (Bypass PWA Gate)

> Userscript chạy Little DaNang (`https://littledanang.oryzen.cloud/`) trực tiếp trên tab trình duyệt (Comet, Chrome, Edge, Cốc Cốc, Firefox, Safari...) mà không cần cài đặt ứng dụng PWA.

---

## ⚡ Cài đặt nhanh bằng 1-Click (Tampermonkey / Violentmonkey)

👉 **[BẤM VÀO ĐÂY ĐỂ CÀI ĐẶT SCRIPT](https://raw.githubusercontent.com/nhoxboo/little-danang-bypass/main/little-danang-bypass.user.js)**

*(Khi bấm vào link trên, Tampermonkey sẽ tự động hiện cửa sổ xác nhận, bạn chỉ cần bấm **Install / Cài đặt** là xong!)*

---

## 🛠 Tính năng
- **Bypass Install Gate:** Tự động giả lập môi trường Standalone PWA (`navigator.standalone`, `window.matchMedia`), vượt qua màn hình chặn bắt buộc cài đặt.
- **Trang chủ:** Thay thế nút cài đặt thành nút **"🚀 Vào chơi ngay"** dẫn thẳng tới `/play/`.
- **Hỗ trợ mọi trình duyệt:** Comet Browser, Chrome, Edge, Cốc Cốc, Brave, Firefox, Safari...
- **Auto-Update:** Tự động nhận bản cập nhật mới nhất từ GitHub khi có thay đổi.

---

## 🎮 Cách sử dụng
1. Cài đặt tiện ích mở rộng [Tampermonkey](https://www.tampermonkey.net/) trên trình duyệt của bạn.
2. Bấm vào link cài đặt script ở trên.
3. Truy cập vào game: **https://littledanang.oryzen.cloud/play/** và tạo nhân vật / đăng nhập để chơi ngay!
